# Product Requirements Document

## Project Overview
**Name:** link_bookmark_app
**Type:** web_application
**Created:** 2026-11-01T19:44:14.222697

## Description
Build a minimal link bookmarking app. User authentication (email/password). Save a link with a title, tag a link, delete a link. List all bookmarks for the logged-in user filterable by tag. (Type: web_app)

## Features
- authentication
- link_saving
- tagging
- link_deletion
- bookmark_listing
- filter_by_tag

## User Stories
### User Authentication
As a user, I want to create an account and log in so that I can access personalized features.

**Acceptance Criteria:** User can register, login, logout, and reset password

## Business Logic
- User registration and login using email/password
- Saving links with titles
- Tagging links for organization
- Deleting unwanted links
- Listing all saved bookmarks
- Filtering bookmarks by tags
